@strana
stitok: ČO TO VLASTNE JE
h1: Claude, ktorý
h2: vidí priečinok.

@text
Claude Code je Claude spustený vo vnútri priečinka. Číta súbory, ktoré tam sú, mení ich, spúšťa príkazy a vie použiť git. Rozdiel oproti chatu nie je v tom, že by bol múdrejší -- je v tom, že medzi ním a tvojou prácou nie je schránka.

@kroky
01 | TERMINÁL | Základná podoba. Napíšeš `claude` v priečinku a začneš písať po slovensky.
02 | EDITOR | Rozšírenie do VS Code / Cursor a plugin do JetBrains. To isté, len s náhľadom zmien.
03 | DESKTOP APP | Samostatná aplikácia. Vidíš zmeny vizuálne, vieš pustiť viac sedení naraz.
04 | WEB | `claude.ai/code` v prehliadači, bez inštalácie. Dobré na dlhé úlohy, ktoré nechceš mať na svojom počítači.

@pravidlo NEJDE LEN O KÓD
Priečinok s dvadsiatimi PDF-kami, tabuľkou a poznámkami je pre Claude Code rovnaký projekt ako repozitár. „Prejdi tie faktúry a sprav z nich prehľad" je úplne legitímne zadanie.

02 | PRIHLÁS SA | Účtom Claude Pro alebo Max. Claude Code je v cene plateného predplatného.
03 | OVER | Napíš `/status`. Uvidíš, ktorým účtom si prihlásený a aký model beží.

@text drobne
Na Windowse sa oplatí mať nainštalovaný Git for Windows -- bez neho Claude Code používa PowerShell namiesto bash-u. Ak inštalácia spadne, `/doctor` a dokumentácia troubleshootingu povedia prečo.

@text
`CLAUDE.md` je obyčajný textový súbor v koreni projektu. Claude Code ho prečíta na začiatku každého sedenia. Je to miesto, kam napíšeš to, čo by si inak vysvetľoval znova a znova.

@terminal CLAUDE.MD — PRÍKLAD
# Pravidlá projektu

- Odpovedaj po slovensky.
- Pred commitom spusti: npm test
- Texty pre klienta píš krátkymi vetami, bez slova „riešenie".
- Súbory v priečinku /archiv nikdy nemeň.

@pojmy
KAM TO DAŤ | `./CLAUDE.md` v koreni projektu. Osobné pravidlá pre všetky projekty patria do `~/.claude/CLAUDE.md`.
AKO DLHÉ | Do 200 riadkov. Dlhší súbor zaberá kontext a Claude sa ho drží horšie.
AKO PÍSAŤ | Konkrétne a overiteľne. „Odsadzuj dvoma medzerami" áno, „formátuj pekne" nie.
RÝCHLY ŠTART | Príkaz `/init` prejde projekt a vygeneruje ti prvú verziu. Potom ju uprav.
ČO TO NIE JE | Nie je to zámok. Sú to inštrukcie, nie vynútené pravidlo -- to sú povolenia.

@strana
stitok: POVOLENIA
h1: Čo smie.
h2: A čo nikdy.

@text
Claude Code sa pýta skôr, než niečo zmení alebo spustí. Čítanie súborov v projekte nepotrebuje súhlas, zápis a príkazy áno. Tri odpovede v tom okne majú rôznu váhu: raz, do konca sedenia, alebo natrvalo.

@kroky
01 | REŽIMY | Predvolený sa pýta pri každom novom nástroji. `plan` len číta a navrhuje. `acceptEdits` automaticky prijíma úpravy súborov.
02 | PRAVIDLÁ | V `/permissions` si nastavíš allow / ask / deny. Vyhodnocujú sa v poradí **deny -> ask -> allow**, prvá zhoda rozhoduje.
03 | ZÁPIS | Trvalé súhlasy si Claude Code ukladá do `.claude/settings.local.json` v koreni repozitára.

@terminal PRÍKLADY PRAVIDIEL
Bash(npm run build)     # povoliť presne tento príkaz
Read(./.env)            # pravidlo pre čítanie jedného súboru
WebFetch(domain:docs.sk)# pravidlo pre jednu doménu
Bash(rm *)              # toto daj do deny a nechaj tak

@pravidlo JEDINÉ PRAVIDLO, KTORÉ NEPORUŠ
Režim `bypassPermissions` vypína pýtanie sa úplne. Používaj ho len v kontajneri alebo virtuálnom stroji, kde nemá čo pokaziť. Na svojom počítači nikdy.

@zoznam
01 | Vytvor si nový prázdny priečinok a skopíruj doň pár svojich súborov -- pokojne texty alebo tabuľky, nie kód.
02 | Spusti `claude` a napíš: „Prejdi súbory v tomto priečinku a napíš mi, čo v nich je."
03 | Potom si vypýtaj skutočnú zmenu: „Vytvor PREHLAD.md so zhrnutím a odkazmi na jednotlivé súbory."
04 | Keď sa spýta na povolenie zápisu, prečítaj si, čo presne chce urobiť. Až potom potvrď.
05 | Vytvor `CLAUDE.md` s troma pravidlami a zopakuj tú istú úlohu. Všimni si rozdiel.

@pravidlo BEZPEČNÝ ŠTART
Prvýkrát to nepúšťaj na priečinok, ktorý nemáš zálohovaný alebo v gite. Nie preto, že by to Claude pokazil naschvál -- ale preto, že sa učíš ty, nie on.
