AI DO PRAXELEKCIA 02.5
NEŽ ZAČNEME
Názov ťa nemá odradiť.

Claude Code je Claude, ktorý vidí priečinok. Číta súbory, mení ich a spúšťa príkazy. To, že sa volá Code, je historické — rovnako dobre prejde dvadsať PDF-iek, tabuľku a poznámky.

A nemusíš na to otvárať terminál. V desktopovej aplikácii Claude je karta Code. Ak už používaš Cowork, aplikáciu máš nainštalovanú a Claude Code v nej nájdeš tiež.

CESTAPRE KOHO
Desktopová aplikáciaAk nechceš príkazový riadok. Karta Code, zmeny vidíš vizuálne.
TerminálAk ti príkazový riadok nevadí. Najviac možností, najrýchlejšie.
Editor / webRozšírenia do editorov a claude.ai/code v prehliadači bez inštalácie.
AK SI NETECHNICKÝ
Choď cez desktopovú aplikáciu. Zvyšok tejto lekcie ukazuje terminál, lebo tam vidíš presne, čo sa deje — ale klikacia cesta vedie k tomu istému výsledku.

POSTUP
Najprv inštalácia. Po jednom príkaze.

Terminál je okno, do ktorého zadávaš príkazy počítaču. Na Macu otvor Spotlight cez Cmd + medzerník a vyhľadaj Terminal. Vo Windows vyhľadaj PowerShell v Štarte. Vyber iba príkaz pre svoj systém.

MAC / LINUX / WSL
curl -fsSL https://claude.ai/install.sh | bash
WINDOWS / POWERSHELL
irm https://claude.ai/install.ps1 | iex
01
Počkaj na dokončenie.
Potom terminál zavri a otvor znova. Príkaz nižšie overí, že je nástroj nainštalovaný.
02
Spusti prihlásenie.
Zadaj claude a dokonči prihlásenie v prehliadači. Ak chceš čerpať predplatné, vyber svoj Claude účet, nie samostatné API účtovanie.
OVERENIE V TERMINÁLI
claude --version
AK TO NEJDE
„Command not found“: otvor nový terminál a pozri návod na inštaláciu. Pri probléme v spustenom Claude Code použi /doctor. Git for Windows je odporúčaný pre Bash; podľa aktuálnej dokumentácie je možný aj PowerShell.

Otvor priečinok a najprv sa pýtaj.

Vytvor si cvičnú zložku.

02

03
Spusti Claude Code.
Zadaj claude. Pri otázke na dôveryhodnosť priečinka skontroluj zobrazenú cestu. Potom /status na kontrolu účtu.
04
Najprv sa pýtaj.
Vlož prvé zadanie nižšie. Over, či našiel správne súbory. Až potom zadaj vytvorenie prehľadu.
TERMINÁL / CESTU NAHRAĎ
cd "CESTA_K_PRIECINKU_AI-test" claude
PRVÉ ZADANIE
Prečítaj 3 poznámky v tomto priečinku. Vypíš názvy a pri každej jednou vetou obsah. Zatiaľ nič neupravuj. Ak súbor nevieš prečítať, povedz ktorý.
DRUHÉ ZADANIE
Vytvor PREHLAD.md: pri každej poznámke názov, 3 hlavné body a prípadné úlohy. Neznáme termíny označ NEUVEDENÉ. Pôvodné súbory nemeň. Na konci over prehľad oproti všetkým 3 vstupom.

AI DO PRAXELEKCIA 02.5
POSTUP
Daj mu pravidlá, ktoré vieš skontrolovať.

CLAUDE.md je textový súbor s pravidlami projektu. Najjednoduchšie je povedať Claude Code, nech ho vytvorí z textu nižšie. Potom ho otvor a prečítaj. /init vie pripraviť východiskovú verziu, /memory slúži na správu pamäte a pravidiel.

VZOR OBSAHU CLAUDE.md
# Pravidlá projektu - Odpovedaj po slovensky, stručne a konkrétne. - Pracuj len s podkladmi, ktoré patria k úlohe. - Chýbajúce údaje označ NEUVEDENÉ. - Výsledky ukladaj do vystupy/. - Pôvodné súbory bez môjho súhlasu neprepisuj. - Pred odovzdaním porovnaj výstup so zadaním.
REŽIM / PRÍKAZNA ČO JE
PlanPreskúmanie a návrh postupu pred realizáciou.
DefaultBežná práca s kontrolou oprávnení podľa nastavení.
acceptEditsAutomatické prijímanie úprav súborov. Nezapínaj bez rozmyslu.
/permissionsSpráva allow, ask a deny. Zákaz má prednosť pred povolením.
/contextUkáže využitie kontextu a načítané pravidlá.
DÔLEŽITÝ ROZDIEL
Veta v CLAUDE.md je inštrukcia, nie technická blokácia. Oprávnenia sa nastavujú zvlášť. Na cvičenie používaj kópie a nezapínaj bypassPermissions.

HOTOVO AŽ VTEDY, KEĎ…
Vieš to zopakovať aj bez tohto PDF.
Claude Code sa spustí v priečinku AI-test.
PREHLAD.md existuje a sedí na 3 vstupy.
CLAUDE.md má konkrétne pravidlá.
Viem nájsť /status, /permissions a /context.
PRE POKROČILÝCH
Pri dlhšej práci si nechaj uložiť stav: cieľ, hotové kroky, otvorené otázky a ďalší krok. Nové sedenie potom nezačínaš vysvetľovaním celej histórie.
ČO S TÝM VIEŠ SPRAVIŤ ĎALEJ
Ľudia bez programátorského vzdelania si takto stavajú vlastné malé nástroje — od trackera tréningov po prehľad, ktorý si roky ťahali v exceli. Opíšeš, čo chceš, po slovensky. Zvyšok je jeho práca.
TERAZ TY
Otvor PREHLAD.md a over všetky body. V 02.6 tú istú prácu deleguješ bez terminálu.
