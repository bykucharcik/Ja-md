Čo to je

Brána medzi tvojím editorom a modelmi

Normálne to ide takto: Claude Code → Anthropic → tvoja karta. S OmniRoute sa medzi ne postaví server, ktorý beží u teba na počítači a rozhoduje, kam request pošle.

Tri veci, ktoré ti to reálne dá:

  • Jeden endpoint namiesto desiatich kľúčov. Všetky nástroje mieria na jednu adresu.
  • Automatický fallback. Rate limit na jednom provideri ťa nezastaví — router prepne na ďalšieho cez štyri vrstvy: predplatné → API kľúč → lacné → free.
  • Kompresia tokenov. Skracuje prompty a výstupy nástrojov, takže na free limity narazíš neskôr.

Aby sme si rozumeli: free tier neznamená, že modely bežia zadarmo z dobroty srdca. Znamená, že OmniRoute vie naraz využiť free kvóty desiatok providerov. Kvóty sa menia — dnes ti provider dá milión tokenov, o mesiac free tier zruší. Preto má dashboard stránku so živým stavom.

Pred štartom

Skontroluj si Node

Toto je jediné miesto, kde to ľuďom reálne padá. Podporované je 22.22.2+ alebo 24.x–26.x. Na starších verziách ti dashboard nabehne ako biela stránka alebo hodí Module did not self-register.

terminál
$ node --version
# ak je to menej ako v22.22.2, nainštaluj 24-ku:
$ nvm install 24 && nvm use 24

Potrebuješ ešte terminál (na Windowse PowerShell alebo WSL) a voľný port 20128.

Postup · klikni na číslo a odškrtni si krok

Šesť krokov

1

Inštalácia

terminál
$ npm install -g omniroute
$ omniroute

Dashboard máš na http://localhost:20128, API na http://localhost:20128/v1.

Ak ti npm vypíše kopu žltých warningov (ERESOLVE, peer, deprecated) — ignoruj ich. Sú to zastarané peer-dependency rozsahy v cudzích balíkoch. Inštalácia prešla, ak vidíš added N packages.

2

Over, že to žije — bez kľúča

Toto ľudí prekvapí: čerstvá inštalácia odpovedá aj bez registrácie a bez API kľúča, lebo pár keyless free providerov je predpojených v auto combe.

terminál
$ curl http://localhost:20128/v1/chat/completions \
    -H "Content-Type: application/json" \
    -d '{"model":"auto","messages":[{"role":"user","content":"Ahoj, funguješ?"}]}'

Príde odpoveď → brána beží.

Živý stav kvót — koľko si minul a koľko zostáva — nájdeš na /dashboard/free-tiers.

4

Vytiahni si kľúč

Dashboard → Endpoints → skopíruj kľúč. Vyzerá takto: sk-xxxxxxxxxxxxxxxx-xxxxxxxxx

Je to tvoj lokálny kľúč do OmniRoute, nie kľúč od providera. Nikam ho neposielaj a nedávaj do repa.

Napoj svoj nástroj

Claude Code — najrýchlejšia cesta

terminál
# načíta živý zoznam modelov a zapíše konfig
$ omniroute setup-claude
# spustí Claude Code cez OmniRoute
$ omniroute run claude

Claude Code — ručne

Vytvor ~/.claude/settings.json:

~/.claude/settings.json
{
  "env": {
    "ANTHROPIC_BASE_URL": "http://localhost:20128",
    "ANTHROPIC_AUTH_TOKEN": "sk-tvoj-omniroute-kluc",
    "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1"
  }
}

Dva detaily, na ktorých ľudia zamrznú.

1. Pri ANTHROPIC_BASE_URL nedávaj /v1 na koniec — Claude Code si /v1/messages dolepí sám. Ostatné nástroje /v1 naopak chcú. Toto je príčina väčšiny 401-iek.

2. Premenné sa čítajú iba pri štarte. Po zmene musíš Claude Code reštartovať.

Codex CLI

~/.codex/config.toml
model_provider = "omniroute"

[model_providers.omniroute]
name                 = "OmniRoute"
base_url             = "http://localhost:20128/v1"
env_key              = "OMNIROUTE_API_KEY"
requires_openai_auth = false

Finálna kontrola

terminál
$ curl http://localhost:20128/v1/models \
    -H "Authorization: Bearer sk-tvoj-omniroute-kluc"

Vypíše ti zoznam modelov, ktoré máš cez pripojených providerov k dispozícii. Ak tam sú, si hotový.

Používanie

Ktorý model písať

ModelKedy
autoDefault. Router vyberá podľa dostupnosti, ceny a zdravia providera a padá cez štyri vrstvy.
auto/fastKeď ti ide o rýchlosť odpovede viac než o kvalitu.
glm/glm-5.2Formát provider/model, keď presne vieš, čo chceš.

Ak auto vyberie iného providera, než si čakal — nie je to chyba, to je presne jeho práca.

Keď ti padajú agenti a automatizácie

Náhodné 429/400/401 pri agentoch na free provideroch rieši rotácia. Nastav v prostredí, kde beží OmniRoute, a reštartuj:

prostredie servera
$ export OMNIROUTE_ROTATE_ON_400=true
$ export OMNIROUTE_CHAT_MAX_HEAVY_IN_FLIGHT=4
$ export OMNIROUTE_CHAT_ADMISSION_QUEUE_MS=5000

Prvý z nich je zďaleka najsilnejší — spraví z tvrdej chyby tichý retry na zdravého providera.

Pozor pri Dockeri. Image má default heap 1024 MB — to stačí na dashboard a chat, ale nie na coding agentov. Na jedného agenta daj -e OMNIROUTE_MEMORY_MB=8192 --memory=10g, inak ti proces spadne na FATAL ERROR pri dlhých kontextoch.

Toto si prečítaj, aj keď preskakuješ

Kde je háčik

Čo je v poriadku: kľúče sa šifrujú lokálne (AES-256-GCM), prompty idú priamo na vybraného providera a telemetria je defaultne vypnutá.

Free tier znamená, že tvoje prompty idú cez cudzie servery. Free providerov je vyše deväťdesiat a každý má vlastné podmienky — nie všetci garantujú, že tvoje dáta nepoužijú na tréning. Katalóg projektu sám označuje 15 providerov ako rizikových z hľadiska podmienok, aby si sa vedel rozhodnúť.

Na hobby projekty, učenie a vlastné veci: super. Firemný kód, klientske dáta, osobné údaje a prístupy cez free tier neposielaj. Na to si nechaj platený alebo lokálny model.
